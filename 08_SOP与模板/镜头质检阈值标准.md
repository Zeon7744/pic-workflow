# 镜头质检阈值标准（pic-workflow · 编程专家质检脚本依据）

> 版本：v1.0 ｜ 编制：视频导演 ｜ 用途：作为镜头质检脚本的评分与判定依据
> 4 维打分：**形变 / 质变 / 迁移 / 偏移**，每维 0-10 分（0=最差，10=最佳）；综合判定 P0/P1/P2。

## 一、四维打分阈值

### 1. 形变（画面内结构/身体变形）

| 分数 | 表现 | 判定 |
|---|---|---|
| 9-10 | 结构完全正常，无变形 | ✅ 通过 |
| 7-8 | 极轻微比例差（非主诉，细看难察觉） | ✅ P2 通过 |
| 5-6 | 明显可见的轻微变形：手指粗细不均、五官轻微错位、肢体衔接生硬 | ⚠️ P1 建议重做 |
| 3-4 | 显著变形：手指>5 或缺失、五官明显错位、肢体扭曲 | ❌ P0 重做 |
| 0-2 | 严重变形：脸部结构性扭曲、肢体断裂、文字乱码 | ❌ P0 必重做 |

**关键规则**：
- 单镜出现 ≥1 处 0-4 分项 → 整体判 P0
- ≥3 处 5-6 分项 → 升级 P0
- 手指/脸/肢体为主要检查部位，抽首/中/尾 3 帧

### 2. 质变（材质/媒介/画风突变）

| 分数 | 表现 | 判定 |
|---|---|---|
| 9-10 | 材质/媒介完全一致 | ✅ 通过 |
| 7-8 | 色温极轻微漂移（±1 档内） | ✅ P2 通过 |
| 5-6 | 材质局部不统一（一处金属变布感），覆盖 <30% 画面主体 | ⚠️ P1 建议重做 |
| 3-4 | 材质不统一覆盖 ≥30% 主体；色板局部断裂 | ❌ P0 重做 |
| 0-2 | 媒介突变（写实↔动漫、2D↔3D）；色板完全断裂 | ❌ P0 必重做 |

### 3. 迁移（跨镜身份外观不一致）

| 分数 | 表现 | 判定 |
|---|---|---|
| 9-10 | 相邻镜头角色外观完全一致 | ✅ 通过 |
| 7-8 | 发丝/褶皱等非特征细节波动 | ✅ P2 通过 |
| 5-6 | 服装细节/饰品增减，但角色仍可辨认（1-2 个特征维度变化） | ⚠️ P1 建议重做 |
| 3-4 | 主角 2 个特征维度同时变化（如发型+服装） | ❌ P0 重做 |
| 0-2 | 主角 3 个以上特征维度同时变化（发型/服装/五官/标志物/体型）→ 改变身份 | ❌ P0 必重做 |

**判定口径**：对比基准为角色卡三视图；跨镜对比取相邻镜头帧。

### 4. 偏移（构图/位置/光线/空间关系偏差）

| 分数 | 表现 | 判定 |
|---|---|---|
| 9-10 | 构图/轴线/光源完全符合分镜意图 | ✅ 通过 |
| 7-8 | 站位 ±5% 内漂移，不影响轴线 | ✅ P2 通过 |
| 5-6 | 光源主方向与基准不一致（变化 20-45° 且无叙事依据）；构图偏离分镜意图但不穿帮 | ⚠️ P1 建议重做 |
| 3-4 | 轴线跳变 45-90°；光源方向变化 >45° 无叙事依据 | ❌ P0 重做 |
| 0-2 | 轴线跳变 >90°；主体位置穿帮；视线完全跳反 | ❌ P0 必重做 |

## 二、综合判定

| 综合级别 | 规则 | 处置 |
|---|---|---|
| **P0 致命** | 任一维 0-4 分，或 P1 项 ≥3 处 | 必须重做该镜 |
| **P1 明显** | 任一维 5-6 分，且 P0 为 0 | 建议重做；成本敏感可接受后调色/重绘兜底 |
| **P2 轻微** | 所有维 ≥7 分 | 通过，记录留档 |

**质检脚本输出**：每镜 `镜头ID | 形变分 | 质变分 | 迁移分 | 偏移分 | 综合级别 | 处置建议`。

## 三、特效黑榜（什么镜头不能用特效）

| # | 黑榜规则 | 说明 |
|---|---|---|
| 1 | 同一镜头堆叠 ≥3 种特效 | 廉价感直接判 P1/P0 |
| 2 | 无叙事依据的随机光效/抖动 | 眩晕感，直接判 P1 |
| 3 | 与画风冲突的特效 | 写实片用卡通粒子 → 质变扣分 |
| 4 | 文字特效遮挡角色面部 | 遮挡主体直接判 P1 |
| 5 | 转场打断连续事件链且无图形/动作/光影依据 | 破坏叙事连贯，判 P1 |
| 6 | 口型/声音类特效（D 类）在 MVP 一期使用 | 一期未开 D 类，出现即黑榜 |

**特效黑榜触发 → 质检脚本标记该镜违规，扣质变/偏移分并提示移除**。
