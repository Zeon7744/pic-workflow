# 角色卡模板（pic-workflow · ② 角色图像）

> 版本：v1.0 ｜ 编制：视频导演 ｜ MVP：3 集×90s 竖版 1080×1920，动漫风
> 档位：T2 基准（10-12GB，主力）→ SDXL-Turbo 768×768；T1（6-8GB，自动降级）→ SD1.5 512×512。引擎自动匹配，模板字段与检查项两档通用。

## 一、角色卡组成（每角色一套）

| 模块 | 内容 | 数量 | 文件名规范 |
|---|---|---|---|
| ① 三视图 | 正面/侧面/背面全身 + 半身特写 | 1 张 | `角色名_三视图.jpg` |
| ② 表情包 | 喜/怒/哀/乐 各 1-2 张 | 4-8 张 | `角色名_表情_喜01.jpg`… |
| ③ 角色设定表 | 身高比例/服装/发型/标志性动作/性格关键词 | 1 份 md | `角色名_设定表.md` |
| ④ 提示词结构化 | 标准化 prompt 模板（中英双语） | 1 份 md | `角色名_提示词.md` |

## 二、三视图生成规范（T2 基准示例）

**档位参数**：
- T2：SDXL-Turbo，768×768，steps 6-8，CFG 1.5-2.5
- T1：SD1.5 自动降级，512×512，steps 20-25，CFG 7
- 竖版成片不改变参考图画幅：**角色锚点图固定 16:9 横版、纯白/浅灰底、多视角**，供后续跨镜生成复用

**三视图 prompt 模板（动漫风）**：

```text
16:9横版动漫角色三视图设定稿，[完整画风基准]，纯白或浅灰背景，无文字无水印。
左侧半身特写（含发型/五官/配饰细节）；右侧正面、侧面、背面全身，头脚完整。
[姓名]，[身份与气质]，[体型]，[五官肤色]，[发型]，[完整穿搭]，[标志物]。
只此一人，静态站姿，不带叙事场景。
```

**一致性硬约束**：
- 三视图必须逐字复用「画风总纲」完整美术基准
- 只改变对象身份/结构/视角/构图，不切换媒介、色板、材质语言、光线逻辑
- 生成后用 `analyze_files` 核对画风与角色细节，不合格只重试该 item，不重做成功项

## 三、表情包生成规范

**情绪清单**（每情绪 1-2 张）：
- 喜：微笑 / 大笑（可含 1 张）
- 怒：皱眉 / 暴怒（可含 1 张）
- 哀：落泪 / 隐忍（可含 1 张）
- 乐：俏皮 / 得意（可含 1 张）

**表情包 prompt 模板**：

```text
16:9横版动漫角色表情设定稿，[完整画风基准]，纯白背景，无文字无水印。
[姓名]，面部特写，[情绪]表情，[眉毛/眼睛/嘴部具体状态]。
仅头部与肩部，同一角色造型完全一致（发型/服装领口/五官）。
```

**硬约束**：表情包发型、服装领口、五官必须与三视图一致——这是跨镜情绪表演的基础。

## 四、角色设定表模板

```markdown
# [角色名] 设定表

## 基本信息
- 姓名：____
- 年龄：____
- 身份/职业：____
- 性格关键词：____（3-5 个，如：外冷内热/毒舌/重情义）
- 气质定位：____（冷峻 / 甜美 / 儒雅…）

## 外形规格
- 身高比例：____（cm + 头身比，如 185cm / 8头身）
- 发型：____（颜色、长度、形状，如：深蓝黑色短碎发）
- 五官：____（眼型、瞳色、眉形，如：剑眉星目/浅灰蓝瞳孔）
- 服装：____（日常主服装 + 备用服装 1-2 套，含颜色材质）
- 标志物：____（武器/饰品/纹身，如：左耳银色耳钉）

## 标志性动作
- ____（如：习惯性单手插兜 / 撩发 / 抱臂）

## 声音（可选，二期口型）
- 音色描述：____（如：清冷男中音，语速偏慢）
```

## 五、提示词结构化（替代 anime-storyboard-generator）

anime-storyboard-generator 不在本项目 Agent 可用技能列表，按视频创作 Skill 的标准化角色 prompt 结构等效产出，字段与质量对齐：

```text
ROLE_CARD: {角色名}
ANCHOR: {三视图 file_path 或 .role 路径}   # 跨镜生成必须复用同一锚点
STYLE_BASE: {逐字复用画风总纲完整美术基准}
PHYSICAL: {身高比例} / {体型} / {发色发型} / {瞳色} / {肤色}
COSTUME: {主服装+材质} / {备用服装}
SIGNATURE: {标志物} / {标志性动作}
PERSONALITY: {性格关键词 3-5 个}
EMOTION_SET: 喜{file} 怒{file} 哀{file} 乐{file}   # 表情包锚点
VOICE: {音色描述，二期}
```
