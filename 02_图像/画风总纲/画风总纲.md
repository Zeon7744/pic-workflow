# 画风总纲（pic-workflow · 全剧统一美术基准）

> 版本：v1.0 ｜ 编制：视频导演 ｜ MVP：3 集×90s 竖版 1080×1920，动漫风
> 本文件是**全剧唯一美术基准**：所有角色卡、场景卡、分镜 prompt 必须逐字复用「统一前缀」，禁止各角色/场景自行临时猜风格。

## 一、画风定义（8 项必填）

1. **媒介与写实度**：日本动画（动漫）风格，2D 手绘质感，非写实非 3D
2. **线条与形体**：干净利落线条，适度形体夸张（头身比 7-8），轮廓明确
3. **色板与对比度**：高饱和干净色板，主色青蓝+暖橙点缀；对比度中高
4. **材质与纹理**：平涂加少量阴影的动画作画质感；发丝、服装有明显层次
5. **光线**：柔和体积光，倾向新海诚式光影；主光方向与色温见各场景卡
6. **细节密度**：中等偏精致；角色面部与关键道具细节优先
7. **镜头风格**：电影感浅景深，常用大特写/中景；运镜平稳
8. **整体氛围**：情绪导向，治愈/热血/悬疑按剧集基调微调但不动基准

## 三、统一 prompt 前缀（所有镜头/角色/场景 prompt 必带）

```text
[统一前缀-STYLE] 日本动画风格动漫插画，干净利落线条，高饱和干净色板（主色青蓝+暖橙点缀），平涂加少量阴影动画作画质感，柔和体积光新海诚式光影，中等偏精致细节密度，电影感浅景深，情绪导向氛围。
```

> 镜头 prompt = 统一前缀 + 景别/视角/运镜/主体状态/光线/情绪/对白归属（见分镜 SOP）。
> 角色 prompt = 统一前缀 + 角色卡锚点（三视图/表情包）。
> 场景 prompt = 统一前缀 + 场景卡设定。

## 四、参考片名（风格对标）

- 对标方向：新海诚系电影感动画（《你的名字》《天气之子》）的光影与氛围；
- 情绪/节奏对标：短剧向热血反转叙事（具体参考片名由红剑/白皇确认后填入，本版留待定）。

## 五、防漂移铁律

- **禁止**跨镜切换画风（写实↔动漫、2D↔3D）
- **禁止**为迁就失配结果改动局部风格；不合格只重试该 item，保留成功项
- 角色/场景/道具的独立 item prompt 必须逐字复用同一基准，只能改对象身份/结构/视角/构图/背景
