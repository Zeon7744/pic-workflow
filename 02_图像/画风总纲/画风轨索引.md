## 四、使用规则

1. 每部剧选定 1 档画风后全剧锁定，**禁止中途切换**
2. 所有角色/场景/镜头 prompt 必须带对应 `[统一前缀-SX]`（见各画风总纲）
3. 定义图作为参考放入生成 item 的 reference_files，全剧共用
4. 换画风 = 重出角色卡 + 场景卡 + 重跑分镜，成本高，选前先定
5. LoRA 名以 matrix.yaml 实际配置为准，本索引为字段规范
6. 引擎已扩至 S9，S6-S9 的 image/video model 与 lora 字段以 matrix.yaml 为准（S6/S7 走 sdxl/sd15 + wan13b；S8/S9 走 flux/sdxl_turbo + wan13b_fa）
