# 画风总纲 S1_anime_jp（日系 2D 动漫）

> 版本：v1.1（完善） ｜ 编制：视频导演 ｜ 引擎 style key：`S1_anime_jp`
> 全剧美术基准之一：本档为日系 2D 动漫风，适配热血/治愈/校园/恋爱/反转爽剧。

## 一、画风定位与适配剧种

- **定位**：日本动画 2D 手绘质感，情绪导向、受众接受度最高、跨镜最稳
- **适配剧种**：热血逆袭、校园恋爱、治愈日常、甜宠反转、系统流爽剧
- **参考对标**：新海诚系光影（《你的名字》《天气之子》），短剧向热血反转叙事

## 二、画风定义（8 项必填）

1. **媒介与写实度**：日本动画（动漫）风格，2D 手绘质感，非写实非 3D
2. **线条与形体**：干净利落线条，适度形体夸张（头身比 7-8），轮廓明确
3. **色板与对比度**：高饱和干净色板，主色青蓝+暖橙点缀；对比度中高
4. **材质与纹理**：平涂加少量阴影的动画作画质感；发丝、服装有明显层次
5. **光线**：柔和体积光，倾向新海诚式光影；主光方向与色温见各场景卡
6. **细节密度**：中等偏精致；角色面部与关键道具细节优先
7. **镜头风格**：电影感浅景深，常用大特写/中景；运镜平稳
8. **整体氛围**：情绪导向，治愈/热血/悬疑按剧集基调微调但不动基准

## 八、防漂移铁律

- 禁止跨镜切换画风（写实↔动漫、2D↔3D）
- 禁止为迁就失配结果改动局部风格；不合格只重试该 item，保留成功项
- 角色/场景/道具独立 item prompt 逐字复用同一基准，只能改对象身份/结构/视角/构图/背景
