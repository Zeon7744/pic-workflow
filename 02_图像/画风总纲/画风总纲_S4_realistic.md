# 画风总纲 S4_realistic（写实拟真）

> 版本：v1.0 ｜ 编制：视频导演 ｜ 引擎 style key：`S4_realistic`
> 全剧美术基准之一：本档为写实拟真风，适配都市现实/家庭伦理/悬疑刑侦/写实甜宠剧。

## 一、画风定位与适配剧种

- **定位**：照片级写实，真实皮肤/材质/光影，沉浸代入感
- **适配剧种**：都市现实、家庭伦理、悬疑刑侦、写实向甜宠、年代剧
- **参考对标**：电影摄影写实质感（实拍电影调色风格）

## 二、画风定义（8 项必填）

1. **媒介与写实度**：照片级写实，真实人脸/皮肤/材质，非动漫非 3D
2. **线条与形体**：无描边线条，真实骨骼肌肉比例，形体写实
3. **色板与对比度**：自然真实色板，电影感调色；对比度由光线决定
4. **材质与纹理**：真实皮肤质感（毛孔/发丝）、真实服装织物、真实环境材质
5. **光线**：自然光照明暗过渡，真实光源方向与色温；电影感布光
6. **细节密度**：高细节，面部/环境细节真实丰富
7. **镜头风格**：电影感浅景深，标准镜头语言，构图纪实
8. **整体氛围**：沉浸写实，情绪真实可信

## 三、画风定义图

- 文件：`02_图像/画风总纲/画风定义图_写实拟真.jpg`
- 用途：作为风格参考放入每个相关生成 item 的 reference_files，不得只给局部角色用而让其余自由发挥

## 四、可复用提示词前缀（所有镜头/角色/场景 prompt 必带）

```text
[统一前缀-S4] 照片级写实风格，真实皮肤质感毛孔与发丝细节，自然光照明暗过渡，真实材质反射，电影感调色，浅景深，真实骨骼肌肉比例无描边线条，高细节沉浸氛围。
```

> 镜头 prompt = 统一前缀 + 景别/视角/运镜/主体状态/光线/情绪/对白归属
> 角色 prompt = 统一前缀 + 角色卡锚点（三视图/表情包）；场景 prompt = 统一前缀 + 场景卡设定

## 五、主色调 / 光影 / 构图速查

| 维度 | 速查 |
|---|---|
| 主色调 | 自然真实色板，电影感调色 |
| 光影 | 自然光照明暗过渡，电影感布光 |
| 构图 | 电影感浅景深，纪实构图 |

## 八、防漂移铁律

- 禁止跨镜切换画风（写实 ↔ 动漫/水墨）
- 禁止为迁就失配结果改动局部风格；不合格只重试该 item，保留成功项
- 角色/场景/道具独立 item prompt 逐字复用同一基准

## 九、角色卡兼容性

- **已有角色卡（沈临/苏雪晴 动漫三视图）不可直接用于 S4**：需按 S4 画风重出对应角色卡（写实人脸、真实服装材质、真实皮肤质感）
- 角色设定表（服装/发型/标志物）可作参考，但形体/五官需写实化重绘
- **审核提示**：写实人物生成对真人参考图敏感，优先纯文生避免审核拦截
