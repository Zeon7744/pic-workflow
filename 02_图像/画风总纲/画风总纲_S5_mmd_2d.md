# 画风总纲 S5_mmd_2d（二次元 MMD）

> 版本：v1.0 ｜ 编制：视频导演 ｜ 引擎 style key：`S5_mmd_2d`
> 全剧美术基准之一：本档为二次元 MMD 渲染风，适配偶像/舞蹈/动态表演/元气短剧。

## 一、画风定位与适配剧种

- **定位**：MMD 风格二次元渲染，3D 建模感动漫角色，光滑质感，动态生动
- **适配剧种**：偶像歌舞、舞蹈短剧、元气搞笑、动态表演向内容
- **参考对标**：MikuMikuDance 经典渲染质感（MMD 舞台渲染）

## 二、画风定义（8 项必填）

1. **媒介与写实度**：MMD 二次元 3D 渲染，2.5D 质感，保持二次元五官与比例
2. **线条与形体**：3D 模型线条感，形体比例二次元（头身比 6-8），动态幅度大
3. **色板与对比度**：明亮高饱和色板，鲜艳干净；对比度中高
4. **材质与纹理**：光滑质感皮肤与头发，3D 建模反光感，服装有光泽
5. **光线**：舞台/场景三点布光或高亮环境光，发光/半透明材质可用
6. **细节密度**：中高，模型细节与服饰层次清楚
7. **镜头风格**：动态运镜、舞台机位，可旋转/跟拍视角
8. **整体氛围**：活力、元气、表演感，二次元舞台张力

## 四、可复用提示词前缀（所有镜头/角色/场景 prompt 必带）

```text
[统一前缀-S5] MMD风格二次元3D渲染，2.5D质感，二次元五官与比例头身比6-8，光滑质感皮肤头发，明亮高饱和色板鲜艳干净，3D建模反光感材质，舞台三点布光或高亮环境光，动态运镜舞台机位，活力元气表演氛围。
```

> 镜头 prompt = 统一前缀 + 景别/视角/运镜/主体状态/光线/情绪/对白归属
> 角色 prompt = 统一前缀 + 角色卡锚点（三视图/表情包）；场景 prompt = 统一前缀 + 场景卡设定

## 八、防漂移铁律

- 禁止跨镜切换画风（MMD 2.5D ↔ 纯 2D 动漫/写实）
- 禁止为迁就失配结果改动局部风格；不合格只重试该 item，保留成功项
- 角色/场景/道具独立 item prompt 逐字复用同一基准

## 九、角色卡兼容性

- 表情包可复用表情设定，需按 MMD 渲染重绘
