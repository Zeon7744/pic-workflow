# 09 · 教程与培训

用者友好的学习资料 + 快速上手 + 启动指南。给不同阶段的人看，不用查代码。

## 入门路线（由浅入深）

| 文件 | 看谁 | 解决什么 |
|---|---|---|
| `快速上手_10分钟出第一片.html` | 第一次用的创作者 | 10 分钟出第一集，5 步走，含选配置 + FAQ |
| `培训与使用辅助_分角色学习路径.html` | 普通创作者 / 进阶 / MCN 团队 | 你是谁该看哪 + 8 环节人话科普 + 档位/画风剧种速查 + 报错自查 |
| `07_交付与验收/07_启动指南.html` | 要部署跑引擎的人 | 环境准备、一键启动、服务健康检查 |
| `01_项目总览/00_项目简报.html` | 想了解全貌的人 | 项目全貌 + 各阶段资料地图 |

## 怎么用最省心

- **第一次用**：先看 `快速上手_10分钟出第一片.html`，照着做就能出第一集。
- **出问题了**：打开 `培训与使用辅助_分角色学习路径.html` 末尾的「报错自查卡」，对号入座。
- **要给团队培训**：用 `培训与使用辅助_分角色学习路径.html`，按角色分路径讲。

## 配套 Web UI

引擎自带一键出片控制台，启动方式：

```bash
cd pic-workflow
python engine/ui/app.py
# 浏览器打开 http://127.0.0.1:8787
```

粘贴剧本 → 选档位/画风/剧种/集数 → 点「一键出片」→ 看进度 → 下载成片。
用者全程不用碰命令行。
