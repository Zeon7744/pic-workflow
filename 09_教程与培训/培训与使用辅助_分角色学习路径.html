普通创作者 零基础

不会写代码，想把故事做成短剧视频。5 分钟上手，先出片再学。

  • 看「快速上手」教程，跟着出第一片
  • 学「8 环节人话版」，懂它在干嘛
  • 掌握「档位怎么选」，别选错
  • 遇报错翻「报错自查」
进阶创作者 会调参

会写剧本，想让画面/声音更精致。重点学调优。

  • 画风 / 剧种速查，按调性选
  • 单环节精调（哪一步不满意改哪一步）
  • 断点重出：只重做改过的镜头
  • 四维风格矩阵（画风×音乐×声音×BGM）
MCN / 团队 批量出片

多账号、多剧种、要稳定产出。重点是效率和质量门控。

  • 批量剧本 → 批量出片（剧本库化）
  • 质量门控阈值（镜头质检标准）
  • 角色一致性检查（同一角色不串脸）
  • 多机对比 / 横向迭代（1060 等实机数据）

不用记术语，看懂这 8 步就明白它在干嘛。

1
拆剧本
把你的故事切成一个个镜头
2
画角色

3

每个镜头怎么拍（景别/动作）
4

5

你的情况选说明

出片报错？先查这张自查卡

90% 的报错在这 6 条里。对号，照做。

① 页面打不开 / 转圈不动
先确认服务在跑。终端里 python engine/ui/app.py 有没有报错？有没有装好依赖？没装先 pip install flask。终端正常但浏览器卡，刷新再试。
② 点"一键出片"没反应 / 卡很久
正常出片要 30 秒~2 分钟。第一次跑含环境自检会更久。超过 5 分钟还没动静，看终端有没有红字（报错信息），对照下面 ③④。
③ 某一步显示"失败"（红色 ✗）
看是哪一步：
  • · 「生视频」失败 → 显存不够，档位调高一档（T1 改 T2）或剧本镜头数减一点
  • · 「配乐」失败 → 换下剧种（BGM 库对应的可能没数据）
  • · 其他环节失败 → 多半是网络（云端出片断网），检查网络后重出
它会自动降级重试，多数情况重试后能过，看最终成片是否 ok。
④ 出片了但画面很糊 / 太快
档位选了 T0/T1 但想要高清 → 换 T2 重出。镜头太长 → 把剧本拆成更短的场景（每场动作集中一点）。
⑤ 角色前后脸不一样（串脸）
这是角色一致性问题。同一角色的特征在剧本里描述保持一致（发型/服饰/配饰固定），不要每场都换形容。进阶可看「角色一致性检查清单」。
⑥ 完全不知道咋回事 / 报了一堆红字
把终端里的报错信息原样复制，发到 GitHub Issue，或直接群里问。别自己瞎猜。
