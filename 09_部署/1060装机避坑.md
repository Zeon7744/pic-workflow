# 1060（Pascal）ComfyUI 装机避坑 SOP

> 2026-10-24 白皇实机踩坑结论固化。1060 6GB + 秋葉 v3.2 整合包，从"装不上"到"能起 8188"的完整避坑链。

## 结论速查（先记这几条）

| 项 | 1060 必须这样做 | 为什么 |
|---|---|---|
| CUDA 版本 | **必须 cu126 兼容版** | cu129/cu130 在 Pascal CC 6.1 报 `no kernel image available`，强开必崩 |
| 启动参数 | 去掉 `--cuda`，加 `TORCH_CUDA_ARCH_LIST=6.1` | 新版 ComfyUI 的 `--cuda` 与 `--cuda-device/--cuda-malloc` 歧义报错；Pascal 要按 CC 6.1 编译目标 |
| 显存策略 | `--lowvram --fp16-vae --high-ram` | 6GB 紧，吃 32GB 内存 offload |
| 量化 | GGUF Q4_K_M | 1060 不支持 FP8，Q4 最省 |
| 底模 | 必须预放 SD1.5 到 `models/checkpoints/` | 秋葉整合包不预装底模，checkpoints 空则出图报 `model not in []` |
| 驱动 | ≥530，实测 577.00 可稳定支持 cu126 | 太老的驱动 cu126 都不认 |

## 报错对照表（对号入座）

| 报错原文 | 根因 | 解法 |
|---|---|---|
| `main.py: error: ambiguous option: --cuda could match --cuda-device, --cuda-malloc` | 新版 ComfyUI 参数歧义 | 启动参数**删掉 `--cuda`**（默认就走 GPU） |
| `CUDA error: no kernel image is available for execution on the device`（KSampler 阶段） | Torch cu129+ 没编译 Pascal CC 6.1 的 kernel | **换 cu126 兼容版** + 注入 `TORCH_CUDA_ARCH_LIST=6.1` |
| `CheckpointLoaderSimple: v1-5...safetensors not in []` | `models/checkpoints/` 文件夹是空的，没底模 | 下 SD1.5 底模放 `checkpoints/`，下拉重选 |
| `Could not detect model type of ...ControlNet...` | ControlNet 文件被底模扫描器误扫 | 不影响出图；要消掉就把 ControlNet 的 `.safetensors` 只放 `controlnet/`，别放 `checkpoints/` |

## 1060 专用启动脚本 `run_1060.bat`

放在整合包根目录 `D:\ComfyUI\aki\`：

```bat
@echo off
chcp 65001 >nul
cd /d %~dp0
set TORCH_CUDA_ARCH_LIST=6.1
set NVIDIA_TF32_OVERRIDE=0
python\python.exe ComfyUI\main.py --lowvram --use-pytorch-cross-attention --fp16-vae --high-ram --port 8188
echo =================================================
echo  若浏览器没自动打开，手动访问: http://127.0.0.1:8188
echo  关闭本窗口 = 停止 ComfyUI
pause
```

> 注意：整合包内嵌 Python 目录可能叫 `python\`、`.venv\` 或 `venv\`，**以你解压后实际看到的为准**改第一行路径。

## 启动后验证（3 条命令）

```bat
:: 1. 验 CUDA 是不是 12.6（不是 12.9/13.0 就对了）
cd /d "D:\ComfyUI\aki"
python\python.exe -c "import torch; print('CUDA:', torch.version.cuda)"

:: 2. 验 kernel 能不能真跑（提前暴露 no kernel image）
python\python.exe -c "import torch; a=torch.randn(4,4,device='cuda'); print('kernel OK:', (a@a).shape)"

:: 3. 验 1060 被识别
nvidia-smi
```

`nvidia-smi` 看 Driver Version（≥530）和 CUDA Version（驱动支持的最高 CUDA）。

## 出图前的显存纪律

1060 6GB 紧张，出图前**先关掉抢显存的桌面应用**（浏览器多标签、视频软件、输入法后台渲染等）。`nvidia-smi` 看到桌面占用别超 1GB，留足 4-5GB 给 ComfyUI。

## 引擎侧对接

引擎 `engine/config/comfyui/comfyui_T1.yaml` 已固化以上全部结论：
- `launch.env` 注入 `TORCH_CUDA_ARCH_LIST=6.1` / `NVIDIA_TF32_OVERRIDE=0`
- `torch_cuda.recommended=cu126`，`forbidden=[cu129, cu130]`
- `args` 不含 `--cuda`（避免歧义）
- `required_base_model` 提示需预放 SD1.5 底模

`engine/src/picwf/hw_probe.py` 提供：
- `pascal_launch_advice(profile)` → 探到 Pascal CC 6.1 时自动给出 cu126 推荐 + env + 去 `--cuda` + 底模检查建议
- `kernel_selfcheck()` → 跑最小 CUDA matmul，提前暴露 no kernel image（Pascal 装错 CUDA 版本时立刻红）

1060 机装通后，实机跑一张 512×512 图，把真实 `shot_elapsed_s / peak_vram_gb` 回填 `engine/config/record_metrics.yaml`，覆盖当前 cloud 估算的 T1 基线。
