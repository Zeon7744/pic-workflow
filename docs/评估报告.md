## 三、Agnes AI 融合验证

### 3.1 图像生成（agnes-image-2.5-flash）
- **API**: POST https://api.agnes-ai.cn/v1/images/generations
- **测试状态**: 通过
- **测试结果**: 文生图成功返回 URL
- **支持**: size 1K/2K/3K/4K, ratio 1:1/16:9/9:16 等
- **环境变量**: AGNES_IMAGE_API_KEY

### 3.2 视频生成（agnes-video-2.5-flash）
- **API**: POST https://api.agnes-ai.cn/v1/videos
- **测试状态**: API 通路正常，队列繁忙（HTTP 503 排队）
- **限制**: size=720P固定, 最多5张图/3段音频, 不支持videos输入
- **三种模式**: text / keyframe / reference
- **价格**: 免费额度内 ¥0/秒
- **环境变量**: AGNES_VIDEO_API_KEY

## 七、风险与限制

1. **视频队列限流**: agnes-video-2.5-flash 免费额度内并发有限，高峰期返回 HTTP 503
   - 建议：错峰生成、分批提交、加退避重试
2. **size限制**: Flash仅支持720P，不支持1080P
   - 建议：T4/T5本地模型优先使用wan22_14b_1080
3. **reference模式图片上限5张**
   - 建议：orchestrator端做截断保护
4. **API Key安全**: api_keys.env已加入.gitignore，不入库

## 八、后续优化建议

1. **adaptive反哺**: 实机OOM后自动将本地实现降级到链尾，云端顶链首
2. **风格一致性**: 引入CLIP四维质检（shape/style/place/intent），低分镜头自动重做
3. **多模态参考**: T4/T5支持图片+音频双参考生成视频，提升一致性
4. **断点重跑**: orchestrator每步落state.json，失败镜头重做而非整集重跑
